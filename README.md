**Telegram Stories campaigns, from brief to publication.** We connect advertisers with creators and build open-source tools for preparing story media and tracking links.

## Campaign toolkit

**[Plan a placement](https://github.com/TONstories/TON-Stories)**  
Copy a creator brief and agree on the audience, deliverables and reporting window.

**[Check story media](https://github.com/TONstories/telegram-story-preflight)**  
Check local images and videos before sending them to the Telegram Bot API.

**[Audit campaign links](https://github.com/TONstories/campaign-link-audit)**  
Catch missing UTM tags, duplicate parameters and inconsistent names in a media plan.

## Open-source contributions

- **[AstrBot](https://github.com/AstrBotDevs/AstrBot/pull/11285)** · Preserve the caption when it appears on a later item in a Telegram album.
- **[Apache Airflow](https://github.com/apache/airflow/pull/77383)** · Honor a workflow’s link preview settings when it sends a Telegram message.
- **[Huginn](https://github.com/huginn/huginn/pull/3850)** · Keep messages and captions that contain only emoji or punctuation.

We also maintain [CLI Docs Check](https://github.com/TONstories/cli-docs-check), which finds stale command-line flags in README examples.
