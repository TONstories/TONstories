# TON Stories

We build tools for advertisers, Telegram creators and developers. TON Stories connects advertisers with creators for campaigns in Telegram Stories. [TON Stories](https://tonstories.com/?utm_source=github&utm_medium=referral&utm_campaign=open_source&utm_content=profile) · [Telegram](https://t.me/TON_Storiesbot?start=gh_profile)

[Руководство по рекламе в Telegram Stories](https://github.com/TONstories/TON-Stories)

- [CLI Docs Check](https://github.com/TONstories/cli-docs-check) — Find stale flags in fenced shell examples using saved help output.
- [Telegram Story Preflight](https://github.com/TONstories/telegram-story-preflight) — Check local story media before uploading through the Telegram Bot API.
- [Campaign Link Audit](https://github.com/TONstories/campaign-link-audit) — Catch tracking errors across a CSV media plan before the campaign launches.
