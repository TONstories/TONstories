# TON Stories

**Advertising with creators on Telegram Stories.** We connect advertisers with creators and build open-source tools for the work behind a placement, from checking the first video to measuring the links viewers open.

**[Visit TON Stories ↗](https://tonstories.com/?utm_source=github&utm_medium=referral&utm_campaign=open_source&utm_content=profile)**　·　**[Open the Telegram bot ↗](https://t.me/TON_Storiesbot?start=gh_profile)**　·　[Руководство на русском](https://github.com/TONstories/TON-Stories/blob/main/README.ru.md)

## Before a story goes live

| What are you working on? | Start here |
| --- | --- |
| Planning a placement with a creator | **[Campaign guide](https://github.com/TONstories/TON-Stories)** · Copy a brief and agree on the viewer action, deadline and reporting window. |
| Sending a story to the Telegram Bot API | **[Telegram Story Preflight](https://github.com/TONstories/telegram-story-preflight)** · Check local images and videos before upload. |
| Handing off a spreadsheet of tracking links | **[Campaign Link Audit](https://github.com/TONstories/campaign-link-audit)** · Find missing UTM fields, duplicate keys and inconsistent spelling in a CSV. |

Maintaining a command-line tool? **[CLI Docs Check](https://github.com/TONstories/cli-docs-check)** compares flags in your README examples with the command’s saved help output.
